# Трекер привычек (MyHabitTracker)

Консольное приложение на C# для отслеживания ежедневных привычек с сохранением прогресса в текстовый файл (`habits.txt`) в формате CSV

## Возможности
- **Просмотр списка привычек:** отображение названия, текущей серии дней (streak) и статуса выполнения за сегодня
- **Добавление новых привычек:** создание привычек через консольное меню
- **Отметка выполнения:** фиксация прогресса за текущий день с автоматическим увеличением счётчика серии
- **Сохранение данных:** автоматическая загрузка привычек из `habits.txt` при старте программы и запись изменений при выходе

## Структура проекта
- `Program.cs` — точка входа, консольное меню и обработка ввода пользователя
- `Habit.cs` — модель привычки с методами сериализации в строку CSV (`ToCsvLine`) и десериализации (`FromCsvLine`)
- `HabitManager.cs` — управление коллекцией привычек, чтение и запись данных через `StreamReader` и `StreamWriter` с обработкой исключений
- `StreamExamples.cs` — базовые примеры работы с потоками ввода-вывода

## Формат хранения данных
Данные сохраняются в файл `habits.txt` построчно в формате:
```text
НазваниеПривычки;КоличествоДнейПодряд;ВыполненоСегодня
```
Пример:
```text
Читать 30 минут;5;True
Утренняя зарядка;2;False
```

## Запуск проекта
1. Клонируйте репозиторий или скачайте исходный код:
```bash
git clone https://github.com
```
2. Перейдите в папку проекта и запустите приложение:
```bash
cd MyHabitTracker
dotnet run
```
*(Или откройте файл `MyHabitTracker.csproj` в Visual Studio и нажмите **F5**)*
